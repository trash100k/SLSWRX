# SalesWorx — Current State Audit (Forensic)

_Produced 2026-07-07 by a 4-agent parallel audit of every screen and module. Status legend: **FUNCTIONAL** = wired to the real Gemini backend; **PARTIAL** = some real wiring, significant fake parts; **STUB/MOCK** = pure set dressing (hardcoded data, setTimeout-simulated AI, dead buttons)._

## Verdict in one line

A real, working AI core (six Gemini endpoints in `server.ts`, three bosses, the Arena → PostCall loop) surrounded by a shell of cinematic mockups — every social, competitive, and progression surface is set dressing on client-trusted localStorage.

### `src/components/Arena.tsx` — `/arena?boss=<id>`

- **Purpose:** Core 1v1 roleplay call screen: text chat against a boss persona styled as a Final Fantasy battle, with sentiment-as-HP bar, call timer, voice dictation, mid-call 'Scan Enemy' hint, and hang-up handoff to PostCall grading.
- **Status:** FUNCTIONAL — real /api/chat and /api/hint round-trips drive the conversation and sentiment; the only fake parts are cosmetic openers and the ignored ranked param
- **API calls:** /api/chat (handleSend, lines 156-163); /api/hint (handleGetIntel, lines 128-135)
- **State:** localStorage 'custom_boss' read at line 17 when ?boss=custom; static BOSSES import otherwise; transcript held only in component state and passed to /post-call via router location.state (line 181) — lost on refresh
- **Mechanics:** Sentiment 0-100 HP bar seeded at 40/'Skeptical' (line 29) and updated from /api/chat response; call-duration timer (lines 85-93) is display-only with no time limit or gameplay effect; no win/lose condition in-screen — the call only ends when the user clicks FLEE BOUNDARY, which navigates to /post-call; hint disabled until 2+ messages (line 124).
- **Gaps / what is fake:** 1) 'Voice' is browser Web Speech API dictation into the text input (lines 35-82) — no live voice roleplay, no TTS for the boss, and continuous-mode transcripts just append to the input box. 2) Boss opening lines are hardcoded per bossId (lines 111-119), not generated — a generated custom boss always opens with the same canned 'I only have two minutes.' 3) RankedHub redirects here with ?ranked=true but Arena reads only searchParams.get('boss') (line 13), so ranked mode silently degrades to a default casual Greg call — none of RankedHub's advertised rules (60s turn timer, forfeit, lethal KO) exist anywhere in this file. 4) fetch errors are console.error'd and swallowed (lines 138-139, 172-173): a failed /api/chat leaves the user's message with no reply and no retry UI. 5) No abandonment penalty, no attempt limit, no persistence of in-progress calls.
